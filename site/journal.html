Capture Architecture

Write once. Reuse everywhere.

The target workflow is intentionally simple enough to fit real trading: journal the trade in Discord, preserve the raw note, normalize it later, connect it to Signal Bridge events, and only publish educational material after review.

01Discord journal postFast, short-form note while the trade is fresh.
02Private captureRaw text and source reference are stored without public exposure.
03NormalizeSymbol, direction, setup, result, tags, screenshots, and signal link become structured fields.
04ReviewSeparate what actually happened from hindsight and research interpretation.
05Publish / researchApproved lessons can feed education, strategy evidence, and future testing.
Private-first by design. The current beta website is publicly reachable, so raw Discord journal posts should not automatically become public website content. The journal API stores entries as PRIVATE by default; the public page only reads entries explicitly marked PUBLISHED.
