What the chart should show

One clean execution overlay instead of seven stacked indicators.

The Strategy Playbook explains how setups are traded. This page is different: it defines the chart tools that measure and display the information — ORB structure, sessions, liquidity, HTF context, VWAP/EMA, confirmation markers, the decision panel, and Signal Bridge alerts.

Target Chart Stack

The final overlay is a set of transparent modules.

The visual research pack says price must remain the star. Structure stays visible, labels stay sparse, and every module can be toggled because every module has a specific job.

OR

Opening-Range Structure

8:00–8:15 range box with ORH, ORL, ORM, range size, historical ranges, optional labels, custom session/timezone, and an oversized-range filter.

  • Frozen range after build
  • Historical ORs preserved
  • Box + extension lines
  • Range validity separate from trade validity
Core
SE

Session / Killzone Map

Asia, London, New York AM, lunch, and PM context with light boxes, session highs/lows, optional pivots, and drawing limits so the chart stays readable.

  • Custom sessions
  • Low-opacity zones
  • Pivots extend until invalidated/cutoff
  • Labels reduced by default
Context
HTF

Higher-Timeframe Context

1H / 4H boundaries, recent highs/lows, optional equilibrium references, and a simple bull / bear / neutral state without opening extra charts.

  • 1H / 4H references
  • Directional context
  • Optional candle boundaries
  • Stops tiny signals from becoming the thesis
Next layer
LQ

Liquidity Map

Prior-day highs/lows, overnight/session extremes, equal highs/lows, and sweep/reclaim state so likely liquidity locations remain visible.

  • BSL / SSL references
  • Equal highs / lows
  • Session liquidity
  • Sweep status
Context
MA

VWAP + EMA Context

A clean session VWAP plus independently toggleable 20 / 50 / 100 / 200 EMAs. No extra bands or clutter unless they earn a real job.

  • VWAP from chart price source
  • Each EMA individually toggleable
  • Current chart color language preserved
  • Context, not automatic signal
