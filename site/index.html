Evidence Discipline

No fake certainty.

The site distinguishes project rules from implementation and statistical evidence. A working indicator is not automatically a validated edge, and one profitable configuration does not prove every filter inside it.

Verified

Accepted project rule

Used for governance or an explicitly accepted operating constraint. This label alone does not mean statistical proof.

Testing

Under evaluation

Implemented or observed, but still requires controlled evidence before promotion.

Untested

Hypothesis / module

Interesting idea or coded component without sufficient isolated evidence yet.

Retired

Preserved negative evidence

Failed or superseded ideas stay visible so the project does not relearn the same lesson twice.
