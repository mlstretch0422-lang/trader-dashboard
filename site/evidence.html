Research Map

What we have learned versus what we still need to isolate.

The useful question is not “does ORB work?” It is which combination of clock, location, confirmation, context, risk, and target behavior survives controlled comparison.

StructureORB · sessions · prior levels

Objective levels are easy to compute. Preferred ORB clock and range-quality rules still need matched tests.

→
LocationSweep · FVG · edge · midpoint

Multiple candidate locations exist. Their independent contribution is not yet cleanly attributed.

→
ContextHTF · VWAP · EMA · session state

Useful in the discretionary process; each filter needs a defined job and controlled on/off comparison.

→
TriggerReclaim · reject · displacement · MSS

The next attribution harness should compare trigger families on the same underlying opportunity set.

→
OutcomeTarget travel · MAE/MFE · no-trade result

Signal Bridge is being built to store this automatically so future research uses session-level forward records.

Evidence Discipline

Strong presentation does not require fake certainty.

Signal Bridge can lead with its best legitimate work while still keeping evidence type clear.

Implemented

It exists in code

A rule or module is operational and reproducible.

Backtested

A configuration has history

Useful system-level evidence on a defined sample.

Attributed

The component was isolated

Stronger evidence that one specific change helped or hurt.

Forward

Observed in market sequence

Replay, paper, funded, and live stay separated so hindsight cannot quietly become “proof.”
