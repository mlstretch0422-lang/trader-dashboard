Evidence Standard

Strong presentation, strict labels.

The research can look professional without converting historical results into a live-performance claim.

Implemented

Code exists

Rule, indicator, or strategy logic is reproducible in source.

Backtested

Historical configuration

A complete configuration produced historical results on a stated sample.

Attributed

Component isolated

A clock, entry, filter, stop, or exit survives a controlled comparison.

Forward / live

New evidence class

Replay, paper-forward, funded, and live execution remain separate from historical backtests.
