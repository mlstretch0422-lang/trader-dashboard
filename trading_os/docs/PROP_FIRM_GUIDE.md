## Daily Execution (Checklist Format)

### Pre-Market (07:45 ET)

- [ ] Log into broker account (TD Ameritrade, Interactive Brokers, etc.)
- [ ] Pull up ES 1-minute chart (or MES for micro)
- [ ] Check market calendar for events (FOMC, NFP, CPI, earnings)
  - **If major event today**: Skip trading (avoid spikes)
- [ ] Set up watching alerts for ORB breakout

### ORB Window (08:00–08:15 ET)

- [ ] Monitor the high and low prices (don't trade yet)
- [ ] Record ORB high, low, midpoint in trading journal
- [ ] Calculate: ORB_RANGE = HIGH - LOW
  - **If range < 5 pts**: System may not work well (too narrow)
  - **If range > 50 pts**: Possible pre-market spike; caution

### Entry Phase (08:15–11:00 ET)

**For LONG entries:**
- [ ] Wait for close > ORB_HIGH
- [ ] Check: Close > VWAP (required filter)
- [ ] If both true: Enter 1 MES at market/limit

**For SHORT entries:**
- [ ] Wait for close < ORB_LOW
- [ ] Check: Close < VWAP (required filter)
- [ ] If both true: Enter 1 MES at market/limit

**Stop Loss & Targets:**
- [ ] Set stop at entry ± 50 points (ORB edge)
- [ ] Set TP1 at entry + 50 points (1R) — exit 25% position
- [ ] Set TP2 at entry + 100 points (2R) — exit 25% position
- [ ] Set TP3 at entry + 150 points (3R) — exit 25% position
- [ ] Let remaining 25% run to SL or 11:00 ET close

### End of Day (11:00 ET)

- [ ] **FORCED FLAT**: Close all positions (no overnight risk)
- [ ] Log daily P&L: ___________
- [ ] Check daily loss: Did it exceed $500? If yes, STOP trading today
- [ ] Log entry reasons, exit reasons, any execution issues
- [ ] Psychological notes: Followed rules? Any fear/greed?

## Troubleshooting

### "I hit my daily loss limit. What now?"

1. Close all positions immediately
2. Stop trading for the rest of the day
3. Document what happened in your journal:
   - Was it bad luck? (Unexpected spike?)
   - Was it a rule violation? (Entered in wrong zone?)
   - Was it execution? (Slippage worse than expected?)
4. Resume trading tomorrow (fresh daily limit)
5. If this happens 3+ times per month: Revisit system design

### "My drawdown exceeded 15%. What do I do?"

1. Reduce position size to 50% (0.5 MES instead of 1)
2. Continue trading but at reduced size
3. Focus on consistency (get back to break-even)
4. Once recovered to max DD: Resume normal size
5. Document: What market regime caused this? Changes needed?

### "I can't follow the rules consistently. Should I keep trading?"

**No.** Stop trading and revisit:
- Is the system boring? (Normal for consistent systems)
- Are you scared of losing? (Revisit risk sizing)
- Are the rules too complex? (Simplify if possible)
- Do you need accountability? (Find trading partner or coach)

**Do not paper trade with live-trading psychology.**
