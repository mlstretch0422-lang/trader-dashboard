## 📋 DETAILED PRE-ENTRY CHECKLIST

### SECTION A: ORB CALCULATION (08:00-08:15 ET)

- [ ] Check ORB high (highest bar in window)
- [ ] Check ORB low (lowest bar in window)
- [ ] Calculate ORB range: ORB_HIGH - ORB_LOW = _____ pts
- [ ] Valid range? (4-20 pts)
  - [ ] Range > 4 pts? YES
  - [ ] Range < 20 pts? YES
  - [ ] **ORB VALID: YES**

If ORB is choppy (< 4 pts) or too wide (> 20 pts) → **SKIP THIS TRADE**

**Filter 2: EMA Alignment**
- Is EMA 20 above EMA 50? → [ ] YES [ ] NO
- Is EMA 50 above EMA 200? → [ ] YES [ ] NO
- (Both must be TRUE for uptrend)
- Result: _______________

**Filter 3: Volume Confirmation**
- Is current volume > 1.5x average? → [ ] YES [ ] NO
- (Strong volume = institutional participation)
- Result: _______________

**Filter 4: Displacement Candle**
- Is candle body > 2x average body size? → [ ] YES [ ] NO
- (Strong move = momentum confirmation)
- Result: _______________

**CONFLUENCE SCORE:**
- [ ] 4+ filters aligned = STRONG ENTRY (HIGH PROBABILITY)
- [ ] 3 filters aligned = GOOD ENTRY (STANDARD)
- [ ] 2 filters aligned = WEAK ENTRY (SKIP)
- [ ] 1 filter aligned = NO ENTRY (SKIP)

**Minimum filters to enter: 3**

---

### SECTION C: PRICE ACTION CONFIRMATION (09:30+ ET)

**Scenario 1: Breakout + Retest (Primary)**

- [ ] Did price close ABOVE ORB_HIGH?
- [ ] Did price pull back INTO the ORB range after breakout?
- [ ] Is this a candle closing ABOVE the retest high?
- [ ] Can I see strong candle body (not just wick)?
- All 4 = YES? → **ENTER ON CLOSE**

**Scenario 2: Liquidity Sweep (Alternative)**

- [ ] Did price sweep BELOW a key support level?
- [ ] Did a rejection candle form (closed above sweep)?
- [ ] Is volume high on the rejection candle?
- [ ] Can I see the structure change (higher high after sweep)?
- All 4 = YES? → **ENTER ON CLOSE**
