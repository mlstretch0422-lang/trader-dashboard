# Signal Bridge Brand Assets

This folder contains reusable brand variants:

- `signal-bridge-mark-blue.svg`: primary blue-accent mark
- `signal-bridge-mark-mono.svg`: monochrome mark
- `signal-bridge-wordmark-blue.svg`: blue-accent wordmark
- `signal-bridge-wordmark-mono.svg`: monochrome wordmark
- `signal-bridge-favicon.svg`: favicon asset
- `signal-bridge-app-icon.svg`: square app icon
- `signal-bridge-discord-avatar.svg`: circular Discord avatar

Recommended usage:

- In-app sidebar/header: `signal-bridge-wordmark-blue.svg`
- Favicon: `signal-bridge-favicon.svg`
- PWA/app icon: `signal-bridge-app-icon.svg`
- Discord profile image: `signal-bridge-discord-avatar.svg`
- Print or low-color contexts: monochrome variants
